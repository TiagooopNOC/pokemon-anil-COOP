# Código del mod

Hito 0 contiene únicamente `bootstrap/isolate.rb`, un preload de desarrollo que
redirige guardados antes de inicializar SaveData y Multi Save. Su ejecución en el
runtime real todavía debe validarse. No implementa multijugador.

Los contratos futuros de sesiones, campaña y combates están en
`docs/architecture.md`. No se importó código de VMS ni de los scripts del juego.
